# Explore With Me

Дипломный проект — сервис по организации событий.

## Этап 1: Сервис статистики
Реализован сервис для сбора статистики просмотров событий.

## Дополнительная функциональность
В рамках проекта выбрана следующая дополнительная функциональность:
**Комментарии к событиям.**

### Описание:
* Пользователи могут оставлять комментарии к событиям.
* Возможность редактирования и удаления своих комментариев.
* Просмотр списка комментариев к конкретному событию.
